# Keeper of the Hollow

A quiet 3D exploration game for Android and the browser. No combat, no timers, no way to lose.

- `index.html` is the landing page.
- `3d/` holds the browser build of the game.
- `play/` points old links to Pixel Hollow and By Lantern's Glow, which the 2D game became on 2026-11-15.
- `downloads/` holds the Android APK.

To publish: Settings > Pages > Deploy from a branch > main, folder / (root).
